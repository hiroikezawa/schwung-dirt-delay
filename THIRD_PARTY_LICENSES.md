## DaisySP — MIT

The signal chain (OD -> OD/BC -> delay -> OD/BC -> delay, dry/wet) is the
author's own Daisy Versio patch, written with the Daisy examples
(https://github.com/daisyaudio/DaisyExamples, MIT) as a reference; no example
code is included.

Three DaisySP objects are re-implemented in C in `dsp/dirt_engine.c` with the
same arithmetic: `Overdrive` (Source/Effects/overdrive.{h,cpp}, Copyright (c)
2020 Electrosmith, Corp, Emilie Gillet), `Decimator`
(Source/Effects/decimator.{h,cpp}) and `DelayLine` (Source/Utility/delayline.h),
both Copyright (c) 2020 Electrosmith, Corp. DaisySP itself is not linked.

Source: https://github.com/daisyaudio/DaisySP
